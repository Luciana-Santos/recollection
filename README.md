# Recollection - Uma aplicação web para gerenciamento de arquivos.

</div>

📃 **Descrição**  
Uma aplicação web para gerenciamento de arquivos (imagens, links e textos) de forma eficiente e intuitiva, utilizando tecnologias modernas como React, TypeScript e Supabase.

## **📋 Funcionalidades**

- 🖼️ **Gerenciamento de Arquivos:**  
  Interface interativa: Interface intuitiva para organizar, visualizar e gerenciar arquivos.
- 🔒 **Autenticação:**  
  Sistema de login para proteger os dados do usuário.
- 🔎 **Busca e Filtros Avançados:**  
  Ferramentas para encontrar arquivos rapidamente por nome, tipo, etc.
- ⚙️ **Ações em Massa:**  
  Realize ações como deletar ou adicionar tags em vários arquivos ao mesmo tempo.

---

## **🚀 Tecnologias Utilizadas**

- **Vite**: Para inicialização do ambiente de desenvolvimento.
- **React + TypeScript**: Para criar uma interface interativa, escalável e de alto desempenho.
- **Supabase**: Para autenticação, banco de dados e armazenamento de arquivos.
- **TailwindCSS**: Para estilização e design responsivo.
- **React Query**: Para gerenciar e sincronizar estados de dados assíncronos, como chamadas à API.
- **Zustand**: Para gerenciamento de estado global leve e intuitivo.
